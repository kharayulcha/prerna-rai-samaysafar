# Jest Automation Testing Suite - SamaySafar

Complete automation testing suite for SamaySafar React Native + Expo application using Jest.

## Test Structure

All tests are located in `__tests__/integration/` folder with separate files for each test case.

### 10 Test Cases

1. **Test 1 - Successful Login** (`1.login.success.test.js`)
   - Tests login with valid credentials (bayungraiprerna@gmail.com / Expo5544#@)
   - Validates JWT token generation
   - Checks user data is returned

2. **Test 2 - Login Error** (`2.login.error.test.js`)
   - Tests login failure with invalid email
   - Tests login failure with incorrect password
   - Tests login failure with empty credentials
   - Validates error responses

3. **Test 3 - Forgot Password Success** (`3.forgot-password.success.test.js`)
   - Tests OTP send for registered email
   - Validates OTP response codes
   - Ensures OTP is not exposed in response

4. **Test 4 - Forgot Password Error** (`4.forgot-password.error.test.js`)
   - Tests OTP send failure for non-existent email
   - Tests invalid email format handling
   - Tests empty email rejection

5. **Test 5 - Profile Update Success** (`5.profile.update.success.test.js`)
   - Tests successful profile update with valid data
   - Tests updating individual fields (name, phone, address)
   - Validates new token generation
   - Checks updated user data

6. **Test 6 - Profile Update Error** (`6.profile.update.error.test.js`)
   - Tests profile update with invalid phone formats
   - Tests authorization requirement
   - Tests invalid token rejection

7. **Test 7 - Add Driver** (`7.add-driver.test.js`)
   - Tests adding new driver with valid data
   - Tests driver role assignment
   - Tests duplicate email prevention
   - Validates authorization requirement

8. **Test 8 - Add Parent** (`8.add-parent.test.js`)
   - Tests adding new parent with valid data
   - Tests parent role assignment
   - Tests duplicate email prevention
   - Validates email delivery

9. **Test 9 - Add Route** (`9.add-route.test.js`)
   - Tests adding new route with distance info
   - Tests start and end points storage
   - Tests authorization requirement

10. **Test 10 - Add Student** (`10.add-student.test.js`)
    - Tests adding new student with valid data
    - Tests student role assignment
    - Tests linking to parent (optional)
    - Tests credential email sending

## Timeout Note

API tests may timeout if:
- Backend server is slow
- Network connectivity issues
- API endpoint is unavailable

To increase timeout, add to individual test:
```javascript
it("test name", async () => {
  // test code
}, 60000); // 60 second timeout
```

## Troubleshooting

**Tests timeout:**
- Check if backend server is running
- Verify internet connectivity
- Check API endpoint is accessible

**Import errors:**
- Run `npm install` to ensure all packages are installed
- Clear node_modules: `rm -rf node_modules && npm install`

**Jest not found:**
- Install Jest: `npm install --save-dev jest`
